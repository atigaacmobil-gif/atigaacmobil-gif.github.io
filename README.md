# ATIGA AC MOBIL — Website

Website statis responsif untuk ATIGA AC MOBIL.

## Isi paket
- `index.html` — struktur halaman dan konten
- `styles.css` — desain responsif
- `script.js` — navigasi mobile dan tahun copyright
- `assets/favicon.svg` — favicon

## Publikasi gratis ke GitHub Pages
1. Login ke GitHub dengan akun `atiga-acmobil`.
2. Buat repository publik bernama **atiga-acmobil.github.io**.
3. Upload seluruh isi folder ini (bukan folder induknya) ke root repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu Save.
6. Tunggu proses deploy selesai. Website akan tersedia di https://atiga-acmobil.github.io/

## Catatan sebelum tayang
- Dua visual profesional tambahan disertakan di folder `assets/` dan digunakan pada hero serta galeri. Visual tersebut bersifat ilustratif; foto asli bengkel yang diberikan pemilik tetap disarankan untuk dokumentasi autentik.
- Tautan Instagram dan Facebook sudah diperbarui menggunakan URL yang diberikan pemilik.
- Peta tertanam memakai pencarian alamat; tombol petunjuk arah memakai tautan Google Maps yang diberikan.
- Jam Minggu ditulis “menyesuaikan”, sesuai informasi pemilik.
- Tidak ada klaim sertifikasi, garansi, atau lama pengalaman yang belum dikonfirmasi.
